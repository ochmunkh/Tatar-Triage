# Аюулгүй байдлын загвар

[English](SECURITY-MODEL.md) · [← README](../README.mn.md)

Tatar Triage юуг амладаг, юуг амладаггүй, амлалт бүр хаана шалгагддагийг нэг хуудсанд хэлнэ. Дэлгэрэнгүй нь энд холбосон хуудсуудад байдаг; энэ хуудас бол орох хаалга.

## Юуг амладаг вэ

| Шинж чанар | Юу гэсэн үг | Юу баталгаажуулдаг |
|---|---|---|
| Сүлжээгүй | Сүлжээний дуудлага, телеметри, шинэчлэлт шалгах, акаунт байхгүй | AV-01 ([AV-SAFETY.md](AV-SAFETY.md)) |
| Нууц үгийн материалгүй | Цуглуулагч нууц үг уншдаггүй, credential dump хийдэггүй | AV-02 |
| Хамгаалалтыг хөндөхгүй | AMSI, ETW, антивирусыг хөндөхгүй | AV-03 |
| Уншигдахуйц, далдлаагүй | Динамик эсвэл кодлогдсон гүйцэтгэл байхгүй; ажиллах бүхэн файл дотор бий | AV-04 |
| Эрсдэлтэй үйлдэл сонголтоор | Hive хуулах, бүтэн event-log экспорт, memory dump нь хүсэхгүй бол унтраалттай | AV-05 |
| Юу ч нийлүүлдэггүй | Репод driver, binary байхгүй | AV-06 |
| Хост өөрчлөгдөхгүй | Шалгаж буй хост дээр устгал, эрх солих, үйлчилгээ удирдах, registry бичих үйлдэл байхгүй | AV-07, S8 ба W8 ([SECURITY-TESTING.md](SECURITY-TESTING.md)) |
| Юу ч суулгадаггүй | Үйлчилгээ, хуваарьт даалгавар, cron бичилт, Run түлхүүр байхгүй | AV-08 |
| Цуглуулсан текст чиний хэрэгсэлд ажиллахгүй | Хүснэгтийн томьёо шиг эхэлсэн нүд саармагжуулагдана | AV-09 |
| Нотлох баримт хувийн | Хавтсыг зөвхөн шинжээч бичиж, уншина | S6 ба W5 |
| Хөндөлт харагдана | Өөрчилсөн файл эсвэл manifest илэрнэ; ажилласан скриптийн хэш бүртгэгдэнэ | S9 ба W7 |
| Дайсагнасан оролт бол өгөгдөл | Аргумент, зам, feed файлыг хэзээ ч ажиллуулдаггүй; уншигдахгүй feed нь exit code 2 болгоно | S1-S5, W1-W4, hostile-feed тестүүд |

AV-ийн амлалт бүр эвдэгдэхэд build-ийг унагадаг шалгалттай. Тест өөрчлөлт бүрт ажиллаж, release-integrity gate баримт ба кодыг зөрөхөөс сэргийлнэ.

## Юуг амладаггүй вэ

- **EDR-д харагдана.** Үндсэн гүйлт процесс, сүлжээ, акаунтын төлөвийг уншиж, хэдэн суулгацтай хэрэгсэл ажиллуулдаг. EDR юуг анзаарч болохыг [AV-SAFETY.md](AV-SAFETY.md)-д жагсаасан.
- **Нотлох баримтыг шифрлэдэггүй.** Хэшлэж, шахдаг; шифрлэх нь шинжээчийн ажил ([EVIDENCE.md](EVIDENCE.md)).
- **Цагийг шалгадаггүй.** Цагийн бүсийг бүртгэж, хостын цагийг гаднын эх сурвалжтай тулгаагүй гэж хэлдэг.
- **Finding бол lead, шийдвэр биш,** цэвэр үр дүн хост цэвэр гэдгийг батлахгүй. `tatar.log`-ийн "цуглуулаагүй" хэсгийг унш.
- **Гэрчилгээжсэн, аудитлагдсан бүтээгдэхүүн биш.** [SECURITY-TESTING.md](SECURITY-TESTING.md)-ийн стандартын хуудсууд бол зохиогчийн өөрийн map, хязгаарыг нь хажууд нь бичсэн.
- **Disk image, memory dump-аас биш, ажиллаж буй хостоос цуглуулдаг** ([USAGE.md](USAGE.md)).

## Итгэлийн хил

Гурван газар, гурван түвшний итгэл.

- **Шалгаж буй хост итгэгдэхгүй.** Түүн дээрх файлын нэр, command line, registry утгыг халдагч бичсэн байж болно. Хостоос ирсэн текстийг тайлан эсвэл CSV файлд орохоос өмнө саармагжуулдаг.
- **Нотлох хавтас бол шинжээчийнх бөгөөд нууц.** Шинжээчид хувийн, хостын нууц мэдээлэл агуулдаг, эрсдлийн үнэлгээ эсвэл аудитын тайлантай адил хандах ёстой (хар [README](../README.mn.md)-гийн нотлох хавтасны нууцлалын тухай догол мөр).
- **Шинжээчийн машин шинжилгээний хэрэгслийг ажиллуулна.** Тэд зөвхөн Python-ийн стандарт сан ашиглаж, офлайн ажиллаж, нотлох баримтыг өгөгдөл болгон уншина. Viewer бол сүлжээнд хандахгүй нэг битүүмжилсэн файл.

## Гуравдагч талын код

Репод гуравдагч талын код, binary байхгүй. Python хэрэгслүүд зөвхөн стандарт сан import хийдэг бөгөөд эс бол release-integrity дүрэм build-ийг унагаана. Цуглуулагчид үйлдлийн системийн өөрийн хэрэгслийг ашигладаг. Гадны цорын ганц хэсэг бол memory dump хүсвэл чиний өөрөө гаргаж өгдөг `winpmem` програм; төсөл үүнийг тараадаггүй. Build workflow хэдэн GitHub Action ашигладаг бөгөөд тус бүр нь commit-д бэхлэгдсэн.

## Өөрөө шалга

```bash
python3 .github/scripts/check_av_safety.py .
python3 .github/scripts/check_release_integrity.py .
sha256sum -c SHA256SUMS.txt
```

Эхний хоёр нь репогийн хуулбар дээр ажиллана. Гурав дахь нь татаж авсан release-ийн хавтаст ажиллана; тэнд `SHA256SUMS.txt` (release-ийн хавсралт, репод байхгүй) файлуудын хажууд байх бөгөөд тэдгээрийг нийтэлсэн digest-тэй тулгана. Гүйлтийг юу ч бичихгүйгээр `-DryRun` эсвэл `--dry-run`-аар урьдчилан харж болно.
